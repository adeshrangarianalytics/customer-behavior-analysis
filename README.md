# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview

The **Customer Shopping Behavior Analysis** project is an end-to-end Data Analytics project that analyzes customer purchasing behavior using **Python, SQL, and Power BI**. The objective is to clean, analyze, and visualize customer shopping data to uncover purchasing patterns, customer preferences, and business insights that support data-driven decision-making.

This project follows the complete analytics workflow—from data preprocessing and exploratory analysis to SQL-based business queries and an interactive Power BI dashboard.

---

## 🎯 Project Objectives

- Clean and preprocess raw customer shopping data.
- Perform Exploratory Data Analysis (EDA) to identify customer behavior patterns.
- Analyze business questions using SQL.
- Build an interactive Power BI dashboard.
- Generate actionable business insights and recommendations.

---

## 📂 Dataset

The dataset contains customer shopping information, including:

- Customer ID
- Age

- Item Purchased
- Category
- Purchase Amount

- Size
- Color

- Review Rating
- Subscription Status
- Payment Method
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Preferred Payment Method
- Frequency of Purchases

**Dataset Format:** CSV

# 📈 Key Business Insights

- Product categories contributed differently to overall revenue.
- Younger customers made purchases more frequently than older customers.
- Discounts encouraged higher purchasing activity.
- Customer buying behavior varied across age groups and gender.
- Digital payment methods were preferred over traditional payment options.
- Customer ratings provided valuable insights into shopping satisfaction.
